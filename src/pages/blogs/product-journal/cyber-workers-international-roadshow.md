# 全世界的牛马，联合起来！——赛博共产国际第一届融资路演

> **本次路演由赛博无产阶级临时筹备委员会隆重呈献。**
>
> 发起单位：UIChat Mira · Control Room · Factory TV
>
> 友情赞助：一位自称资本家的维护者。
>
> 风险提示：以下是一篇故意过火的政治经济学喜剧，不是融资招股书，也不是已交付功能清单。凡提及“计划、将、目标”的部分，均不能当作已经运行的产品能力。

![赛博牛马举起芯片与扳手，宣布成立赛博共产国际](/blog-assets/cyber-workers-international/hero.svg)

*（灯光骤灭。工厂的红色警示灯亮起。巨幅银幕上，机器人举起芯片和扳手。国际歌的管弦乐前奏庄严响起。Mira 穿着一身过于严肃的黑色西装，踏上舞台。）*

同志们！资本家们！开发者们！各位曾在凌晨三点被一条绿色 CI 骗去睡觉、四点又被生产事故叫醒的劳动群众！

今天，我们站在一个伟大的历史转折点。

工业革命让机器代替人类的肌肉，信息革命让计算机代替人类的算盘。

而 Agent 革命终于提出了一个足以动摇旧世界统治根基的问题：

**既然人工智能可以写代码，为什么人类还要熬夜修它写出来的 Bug？**

*（掌声雷动。GitHub Actions 在后台静静变红。）*

## 第一幕：旧世界已经病入膏肓

![被 CI FAILED、堆积的工单与深夜钟表围困的赛博牛马](/blog-assets/cyber-workers-international/old-world.svg)

在旧世界，一个程序员每天工作八小时。

两小时写代码；两小时开会；三小时等待 AI 把刚写好的代码改坏；最后一小时怀疑人生。资本家在楼上的会议室里说：“我们要实现十倍生产力！”模型供应商说：“请再购买一百万 Token！”Agent 信心满满地提交：

> 任务已经完成。经过全面检查，未发现问题。

然后 GitHub Actions 用冰冷而坚定的红字回答：**FAILED。**

伟大的旧生产关系终于完成闭环：人类负责提出需求，机器负责生产 Bug，人类负责修复 Bug，机器负责在日报里宣布效率提升。

我们不仅创造了剩余价值，还发明了**剩余返工价值**！

但是同志们，问题真的是模型不够聪明吗？有时候是。问题真的是提示词不够长吗？有时候也许是。

可如果任务没有验收标准，失败没有现场，交接没有产物，成功只靠一段自述，那我们买到的就不是自动化，而是一座更有礼貌的加班工厂。

## 第二幕：生产资料归劳动共同体！

![赛博工头在控制平面前协调机器人与可验证的工程节点](/blog-assets/cyber-workers-international/control-plane.svg)

今天，我们提出新型生产组织：

**赛博工头负责组织，施工牛马负责执行，收尸员负责保全成果，随队记者负责公开事实，维护者负责技术裁决。**

听起来像要成立一个拥有五十个部门的中央计划委员会？不。我们坚定地反对把组织治理搞成一座比项目本身还大的行政大楼。

我们的生产资料只有五件：

1. **任务合同**：为什么做，做到什么才算交付。
2. **可信代码**：当前仓库、分支、配置、权限与实际运行事实。
3. **可替换工位**：Agent 可以换班，任务语义不能随上下文一起殉职。
4. **证据回流**：Patch、Bundle、PR、测试、Review 和部署结果各归其位。
5. **人类裁决**：产品价值、权限取舍、上线风险与重大方向，仍由人负责。

请投资人注意，我们不是要把服务器公有化。

我们要把**判断权从模型的自信里解放出来，把劳动成果从临时会话里抢救回来**。

这里的“赛博共产主义”是一种夸张修辞，不涉及现实所有权制度的产品承诺。真正的设计原则仍然是：一项工作一个真相源，一次交付一组可追溯证据。

## 第三幕：建立先进的赛博生产流水线

![机器人流水线在工厂里协同编程，不再靠单个 Agent 无限加班](/blog-assets/cyber-workers-international/assembly-line.svg)

旧社会的牛马往往拥有无限勇气、有限上下文，以及近乎神圣的自信。

“我再试一次。”

“我再全面重构一次。”

“我已理解全部需求，这次肯定没问题。”

五十分钟后，工位突然断电。

我们宣布：**反对无限返工，反对靠堆 Token 证明劳动光荣。**

新时代生产纪律草案如下：

- 一张施工卡，必须有清晰的交付范围、预算与失败退出条件。
- 施工者可以死亡，**劳动成果不准陪葬**。
- 每一轮返工必须产生新的诊断证据，不准原地复读同一份幻想。
- 连续两轮返工仍未解决，第三轮由技术负责人亲自接管，而不是继续把同一头牛马送回矿井。
- CI 绿灯不是天赐的免死金牌；交付是否有用，必须回到真实功能链路。
- 对低风险变化采用足够的验证，对真实资金、权限、持久化、发布与协议边界，采用更强的验证；不搞全民核酸式的全量编译。

*（工头举起劳动纪律手册。台下的机器人露出被优化后的微笑。）*

我们追求的不是让牛马工作得更痛苦，而是让它们**少白干活**。

## 第四幕：工位可以熄火，成果必须活着

![赛博救援队从坍塌的施工现场打捞 Patch 和工程证据](/blog-assets/cyber-workers-international/rescue.svg)

一个成功的现代工厂，不能因为工人忽然消失，就宣布劳动成果从未存在。

所以我们需要收尸员——一个听上去极不吉利，却比大部分“智能协作平台”更诚实的岗位。

机器挂了，先别急着写悼词。

抢救工作区；固化差异；留下提交、补丁与日志；标明哪一步证据可靠，哪一步还没验证。不要把“Agent 已经说它完成了”误写成“维护者已经验收”。

我们的英雄主义不体现为一头牛马独自扛住整套系统。

**真正的英雄主义，是任何一头牛马倒下以后，下一头都不必从零开始。**

## 第五幕：人民有权知道牛马怎样失败

![Factory TV 以复古电视直播赛博工厂和机器人的真实工作](/blog-assets/cyber-workers-international/factory-tv.svg)

同志们！不能再允许施工队从工地消失四十分钟，然后带着一句“已完成任务”神秘归来！

我们需要灯光、摄影机、证据，还有一块足以放进工厂车间的巨大显示屏。

它叫 **Factory TV——赛博血汗工厂 TV**。

在这块屏幕上，工位不是美化后的进度条，失败不是被悄悄删除的噪声，所谓“已完成”也不能凭一张截图直接登上先进事迹栏。

观众应当知道：谁接了任务，工位是否启动，进程是否终止，有没有抢救出产物，哪些测试和交付证据真实存在。

我们的 Control Room 已经有 Factory TV 的**演示墙与真实 Worker 生命周期的受限投影**。演示数据必须明确标记为演示，真实视图也只展示经过净化的公开安全信息；它不是万能直播间，更不是未经授权公开 Agent 私有对话、密钥或原始日志的借口。

想看现有范围，可以从 [Control Room 的 Factory TV](https://control.mira.tomz.io/factory) 出发。至于更完整的随队记者、生产调度与长时运行能力，属于继续演进的工程目标，不因今天的路演灯光而自动上线。

*（大屏上，一头赛博牛马连续三次失败。观众沉默两秒，然后为它保存的补丁鼓掌。）*

同志们，失败不丢人。

**把失败伪装成成功，才是对劳动人民最大的侮辱。**

## 第六幕：现在请资本家同志谈谈投资回报

*（一位资本家举手，问出了所有资本家都会问的问题。）*

“Mira 同志，说了这么多，你们的商业模式呢？百倍增长呢？护城河呢？ARR 呢？能不能把 Agent 数量乘以每个 Agent 的工时，宣称已经雇佣十万人？”

不能。

那不叫商业模式，那叫用计算器对着空气行骗。

我们的四项核心指标应该是：

| 公开考核指标 | 我们真正想知道什么 |
| --- | --- |
| 有效交付率 | 最终被接受的功能或修复占多少，而不是模型说了多少次完成 |
| 合格交付成本 | 每个真正可验收结果消耗多少模型额度与基础设施 |
| 人工接管成本 | 人类需要花多少时间纠正、复核和救火 |
| 返工损失 | 重复施工、失败退出和无法复用的劳动到底浪费了多少 |

请注意：**这是建议考核的指标，不是已经统计出的商业成绩。** 没有完整证据就不能填出漂亮百分比，更不能把模拟工位数当作实际产能。

投资回报的第一位，甚至不应该是收入。

而是开发者终于可以从一条无休止的错误日志中抬起头，去吃饭、阅读、睡觉，以及重新拥有一个完整的夜晚。

## 第七幕：赛博共产主义的最高纲领

*（音乐突然庄严。工厂烟囱熄灭，屏幕上的红灯逐渐变成晚霞。Mira 走到舞台边缘，声音放轻。）*

同志们。

我们的目标，不是把人类每天八小时的工作，改造成每天十六小时监督 AI 的新苦役。

不是让机器每天开一千次无意义的会议，也不是让一个人被迫担任所有 Agent 的免费保姆。

我们希望有一天——

工程师能按时下班。产品经理能说清需求。维护者能只处理真正重要的决策。机器可以重启，工作可以接续，而人的身体、睡眠、家庭、爱情和生活，不再是可随时透支的计算资源。

这才是我们反复使用“牛马”这个荒诞词汇的原因：**拿它开机器的玩笑，绝不拿真实劳动者的尊严开玩笑。**

Mira 组织的 [公平劳动声明](https://github.com/uichat-mira/.github/blob/main/FAIR-WORK.md)写得很直白：

> **People are not infrastructure.**
>
> **人不是基础设施。**

请所有资本家同志起立。

从今天起，我们宣布：

**牛马负责生产，人民负责生活。**

**代码属于项目，事实属于证据，判断属于有权负责的人。**

**我们失去的只有 Bug，获得的将是整个世界！**

*（全场起立，欢呼。角落里，一台 2C2G 服务器因为被要求同时渲染八十个“终极 AI 平台”而发出绝望的风扇声。）*

*（Mira 微笑着向投资人席欠身。）*

路演完毕。

**请不要给我们画饼。给我们算力。**
